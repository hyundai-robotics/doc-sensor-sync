# 1.6 튜토리얼

이 과정은 센서 동기를 처음 설정하는 사용자가 **입력 신호 확인 → 진행 방향·분해능 설정 → 티칭 → 첫 시험 운전**을 순서대로 진행하기 위한 안내입니다.

### 목표

직선 컨베이어 1대와 작업물 1개를 사용하여 로봇이 짧은 구간에서 작업물을 추종한 뒤 안전하게 이탈하는 동작을 확인합니다.
이 과정은 **로봇 기본 조작과 안전교육을 이수한 사용자**를 대상으로 합니다. 로봇 조작 자체가 처음이라면 제어기 조작 설명서와 안전교육을 먼저 확인하십시오.

{% hint style="warning" %}
이 과정은 설비의 안전 절차를 대체하지 않습니다. [안전 주의 사항](../../0-about-this-manual/safety-notice.md)을 먼저 읽고, 현장의 위험성 평가·인터록·정지 절차를 준수하십시오. 배선 작업은 전원을 차단하고 담당자가 수행해야 합니다. 움직이는 작업물에 손을 대거나 로봇과 컨베이어를 작업공간 내에서 동시에 조작하지 마십시오.
{% endhint %}

### 시작 전 준비

- 기존 센서 동기 설정과 작업 프로그램이 있다면 백업합니다. 기존 생산 프로그램을 덮어쓰지 않고 시험용 프로그램을 준비합니다.
- 지원 I/F 보드, 엔코더, 리밋스위치의 설치·접속을 담당자가 확인합니다. [2. 시스템 구성 및 접속](../../2-system-config-access/README.md)을 참고하십시오.
- 컨베이어를 안전하게 이동·정지시킬 수 있고, 로봇·툴·작업물의 간섭을 확인할 수 있는 시험 환경을 준비합니다.
- 사용할 툴/TCP와 로봇 좌표계가 확인되어 있어야 합니다. 각도 계산에 사용할 프로그램과 시험 프로그램에서 동일한 기준을 사용합니다.
- 첫 시험 속도, 추종 오차의 합격 기준, 안전한 시험 영역을 설비 담당자와 정합니다.(이 설명서의 화면·예제 속도는 권장값이 아닙니다.)

### 알아둘 용어

- **리밋스위치:** 작업물의 진입을 알리는 센서입니다. 작업물 위치를 판단하는 기준점이 됩니다.
- **raw 펄스:** 엔코더에서 받은 raw 펄스 값입니다. 모니터에는 16진수로 표시되며 `0 ~ ffff` 범위를 반복합니다.
- **작업물 위치:** 리밋스위치를 기준으로 작업물이 이동한 위치입니다. 직선 컨베이어의 단위는 mm입니다.
- **엔코더 분해능:** 직선 컨베이어가 1m 이동할 때 발생하는 펄스 수입니다.
- **동기 구간:** 이동하는 작업물에 맞춰 로봇의 위치를 보정하며 재생하는 구간입니다.
