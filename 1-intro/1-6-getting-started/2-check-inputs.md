# 1.6.2 튜토리얼 - 리밋스위치와 엔코더 입력 확인

## 목표와 시작 조건

작업물 감지 신호와 엔코더 펄스가 제어기에 들어오는지 확인합니다. [기본 설정](1-basic-settings.md)을 완료하고, 설비 담당자가 승인한 안전 점검 상태에서 진행하십시오. 로봇 프로그램은 재생하지 않습니다.

## 1. 점검 화면 열기

1. `[모니터링] > [센서 동기]` 화면을 엽니다.
2. 기본 설정에서 사용한 센서를 선택합니다.
3. **리밋스위치 입력**과 **raw 펄스** 항목의 현재 값을 확인합니다.

![센서 동기 모니터 화면](../../_assets/image21.png)

## 2. 리밋스위치 확인

1. 리밋스위치가 동작하지 않을 때 **리밋스위치 입력**이 `0`인지 확인합니다.
2. 담당자가 승인한 안전한 방법으로 실제 리밋스위치를 동작시킵니다.
3. 입력이 `1`로 바뀌고, 동작을 해제하면 다시 `0`이 되는지 확인합니다.

**정상 결과:** 실제 리밋스위치 상태와 화면의 리밋스위치 입력이 일치합니다.

{% hint style="info" %}
모니터링의 `[리밋스위치 동작]` 버튼이나 프로그램의 `cv.input` 명령어는 수동으로 작업물 진입을 인식시키는 기능입니다. 실제 배선의 정상 여부를 확인하는 이번 단계에서는 사용하지 않습니다. 실제 입력과 수동 입력을 함께 사용하면 작업물이 중복 진입한 것으로 인식될 수 있습니다.
{% endhint %}

## 3. 엔코더 입력 확인

1. 로봇과 작업물이 간섭하지 않는 안전한 상태를 확인합니다.
2. 컨베이어를 승인된 점검 속도로 짧게 이동시킵니다. 손이나 툴로 작업물을 누르거나 잡지 않습니다.
3. **raw 펄스**가 이동에 따라 일관되게 증가하거나 감소하는지 확인하고 방향을 기록합니다.
4. 컨베이어를 정지시키고 값이 안정되는지 확인합니다. 정지 중 값이 계속 변하거나 이동 중 값이 불규칙하면 다음 단계로 넘어가지 않습니다.

**정상 결과:** 이동 중 카운터가 변하고 정지하면 안정됩니다. `ffff`에서 `0` 또는 `0`에서 `ffff`로 넘어가는 것은 16 bit 카운터의 순환일 수 있습니다. 단순히 한 번의 값 변화만 보고 입력 이상으로 판단하지 마십시오.

입력 정상 여부를 확인하는 단계입니다. 실제 이동 방향·거리와의 대응은 분해능·각도 설정 이후에 확인합니다.

## 완료 조건

- 실제 리밋스위치 동작과 화면의 리밋스위치 입력이 일치합니다.
- 컨베이어 이동에 따라 raw 펄스가 일관되게 변합니다.
- 정지 시 raw 펄스가 안정되고, 이동 방향과 카운터 변화 방향을 확인했습니다.

## 증상 및 점검 방법

| 증상 | 점검 순서 |
| --- | --- |
| 리밋 입력이 변하지 않음 | 선택 센서 → 리밋 입력 번호 → 일반 I/O 모니터의 해당 입력 → 센서 전원·배선 |
| raw 펄스가 변하지 않음 | 선택 센서 → 16 bit 입력 시작 번호 → I/F 보드 상태·엔코더 접속 → 엔코더 전원·출력 |
| 정지 상태에서도 값이 계속 변함 | 신호 할당 중복, 보드 설정, 배선·노이즈를 담당자와 점검 |

{% hint style="warning" %}
배선과 전기적 신호 점검은 담당자가 안전 절차에 따라 수행하십시오.  
{% endhint %}
