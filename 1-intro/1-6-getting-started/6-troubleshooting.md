# 따라하기 6. 트러블슈팅

예상과 다른 동작이 있으면 먼저 현장의 절차에 따라 설비를 안전하게 정지하십시오. 아래 표는 **정지 후 점검 순서**입니다. 동작 중 배선·신호 번호·분해능을 바꾸거나 안전 인터록을 우회하는 안내가 아닙니다.

### 증상별 점검

| 증상 | 점검 항목 | 점검 단계 |
| --- | --- | --- |
| 리밋스위치 입력이 0 또는 1에 고정됨 | 선택 센서, 입력 번호, 일반 I/O 모니터, 실제 센서 상태·배선 | [2. 입력 신호 확인](2-check-inputs.md) |
| 컨베이어는 움직이는데 raw 펄스가 변하지 않음 | 16 bit 입력 시작 번호, 보드 설정·상태, 엔코더 접속·전원 | [1. 기본 설정](1-basic-settings.md), [2. 입력 신호 확인](2-check-inputs.md) |
| raw 펄스가 ffff에서 0으로 넘어감 | 16 bit 카운터의 정상 순환인지 확인. 위치값의 연속성과 이동 방향도 함께 확인 | [2. 입력 신호 확인](2-check-inputs.md) |
| 실제 이동 거리와 작업물 위치가 맞지 않음 | 직선/원형 선택, pulse/m 단위, 같은 기준점 사용 여부, 미끄러짐, 툴/TCP | [3. 진행 방향·분해능 설정](3-calibration.md) |
| 작업물 1개인데 진입 개수가 여러 개임 | 리밋 신호의 반복 입력, 기존 데이터, 수동 리밋 버튼·cv.input 중복 사용 | [2. 입력 신호 확인](2-check-inputs.md), [5. 재시작](5-first-run.md) |
| cv.wait에서 계속 기다림 | 실제 작업물 인식 여부, 작업물 위치와 대기거리, 컨베이어 이동 여부, 진입 후 리셋 여부 | [4. 프로그램 구성](4-teach-and-program.md) |
| 대기하지 않고 동기 구간으로 진입함 | 기존 작업물 데이터 여부, 실제 위치가 이미 대기거리 이상인지, 대기거리 단위와 명령 배치 | [4. 프로그램 구성](4-teach-and-program.md), [5. 재시작](5-first-run.md) |
| 로봇이 반대 방향 또는 엉뚱한 방향으로 추종함 | 선택 센서, 각도 계산 프로그램·S1/S2 순서, 카운터 설정·배선, 툴/TCP, 스텝의 센서 데이터 | [3. 설정 검증](3-calibration.md), [4. 티칭](4-teach-and-program.md) |
| 추종 오차가 크거나 이탈 때 간섭이 예상됨 | 컨베이어 속도와 로봇의 추종 능력, 진행 방향·분해능, 티칭 기준·스텝 데이터·이탈 경로 | [3. 설정 검증](3-calibration.md), [4. 티칭](4-teach-and-program.md) |
| 중단 후 재생이 첫 시험과 다름 | 남은 작업물, 리셋으로 지워진 데이터, 재생 시작 스텝, 로봇의 현재 위치 | [5. 재시작](5-first-run.md) |

### 에러가 표시될 때

| 에러 | 점검 방향 |
| --- | --- |
| E0019 컨베이어 펄스 허용주파수 초과 | 펄스 입력·보드 설정·실제 운전 조건을 확인합니다. 펄스 이상 검출 허용 횟수를 임의로 높여 해결하지 않습니다. |
| E0021 컨베이어 허용 속도 초과 | 실제 속도, 분해능·단위, 입력 이상, 허용 속도 설정을 함께 확인합니다. 시스템 에러 검출을 무효로 하여 시험을 계속하지 않습니다. |
