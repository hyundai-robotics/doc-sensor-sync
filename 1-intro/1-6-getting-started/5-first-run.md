# 1.6.5 튜토리얼 - 첫 시험 운전과 재시작

## 목표와 시작 조건

작업물 1개로 대기, 동기 추종, 동기 종료, 안전한 이탈을 확인합니다. [티칭과 프로그램 구성](4-teach-and-program.md)의 완료 조건을 모두 만족한 뒤 진행하십시오.

{% hint style="warning" %}
시험은 현장의 안전 운전 절차에 따라 담당자 입회하에 수행하십시오. 로봇 속도만 낮춰도 컨베이어를 추종할 수 있다고 가정하지 마십시오. 컨베이어 속도와 로봇의 추종 능력을 함께 고려해야 합니다. 방호·인터록을 우회하거나, 동작 중 작업공간에 들어가 위치를 확인하지 마십시오. 위험하거나 예상과 다른 동작이 있으면 현장의 정지 절차를 사용합니다. `cv.sync off`나 수동 리셋은 안전 정지를 대신하지 않습니다.
{% endhint %}

## 1. 기동 전 확인

- 로봇의 현재 위치에서 시작 스텝으로 이동하는 경로와 이탈 경로가 안전합니다.
- 시험 작업물은 1개이며, 아직 리밋스위치를 통과하지 않았습니다.
- 초기화 전에 인식된 작업물의 데이터를 계속 사용하지 않도록 시험 순서를 확인했습니다.
- 컨베이어와 로봇의 시험 속도·시험 영역·추종 오차 합격 기준을 담당자와 확인했습니다.
- 공정 출력이 작동하지 않고, 모니터링 화면을 작업공간 밖에서 확인할 수 있습니다.

## 2. 시험 과정

1. `[모니터링] > [센서 동기]`를 열고 사용할 센서를 확인합니다.
2. 승인된 시험 조건에서 프로그램을 시작합니다. 초기화 이후에 작업물을 진입시키도록 설비 순서를 맞춥니다. 초기화와 실제 진입의 순서를 보장할 수 없으면 기동하지 말고 담당자와 인터록을 보완하십시오.
3. 로봇이 대기 위치에 도달한 상태에서 실제 리밋스위치로 작업물 1개를 진입시킵니다. 작업물 투입은 작업공간 밖에서 승인된 방법으로 수행합니다.
4. 모니터링 화면에서 실제 리밋 입력과 진입 작업물 개수, 작업물 위치를 확인합니다. 수동 리밋 입력이나 `cv.input`을 함께 사용하지 않습니다.
5. 작업물이 설정한 대기 거리에 도달할 때까지 로봇이 기다리는지 확인합니다.
6. 동기 구간에서 툴과 작업물의 상대 위치·자세가 유지되는지 안전한 위치에서 관찰하거나 승인된 측정 방법으로 확인합니다.
7. 동기 종료 후 종료 위치로 안전하게 이탈하고 프로그램이 종료되는지 확인합니다. 

## 3. 단계별 정상 결과

| 시점 | 정상 동작 | 이상 시 확인 |
| --- | --- | --- |
| 초기화 후, 실제 진입 전 | 기존 작업물 데이터가 초기화됨 | 리셋 대상 센서·외부 리셋 입력을 확인 |
| 작업물이 리밋스위치 통과 시 | 리밋 입력이 변하고 작업물 1개가 인식됨 | 입력 상태와 수동 입력 중복 여부를 확인 |
| 컨베이어 이동 중 | 작업물 위치(mm)가 이동에 맞게 변함 | 분해능·입력 신호를 재확인 |
| 대기 중 | 대기 거리 도달 전에는 동기 구간으로 진입하지 않음 | 대기 거리와 실행 중인 명령을 확인 |
| 동기 구간 | 추종 방향이 맞고 상대 위치·자세가 정한 기준 안에서 유지됨 | 시험을 정지하고 각도·티칭 데이터·추종 능력을 확인 |
| 종료·이탈 | 동기 구간 종료 후 간섭 없이 안전한 위치로 이동 | 종료 명령 위치와 이탈 경로를 재확인 |

설정한 동기 ON 출력을 외부 I/O로 확인하는 경우에는 출력 할당도 함께 확인하십시오.

## 4. 중단 후 재시작 시 절차

중간 스텝에서 바로 재생하면 작업물 데이터와 로봇 위치의 관계가 달라질 수 있습니다. 첫 실습에서는 다음 순서로 **처음부터** 다시 시험합니다.

1. 현장 절차에 따라 로봇·컨베이어를 안전하게 정지시키고 정지 상태를 확인합니다.
2. 에러와 모니터 값을 기록하여 원인을 해결합니다. [트러블슈팅](6-troubleshooting.md)을 참고하십시오.
3. 남아 있는 작업물을 안전 절차에 따라 정리합니다. 추종 데이터를 지운 작업물을 그대로 이어서 작업하지 않습니다.
4. 프로그램이 정지한 상태에서 필요한 경우 `[수동 리셋]`으로 센서 데이터를 초기화합니다. 이 조작은 펄스·작업물 위치·진입 개수·동기 상태 등을 초기화하므로 대상 센서와 실제 작업물 상태를 먼저 확인합니다.
5. 승인된 수동 조작 절차로 로봇을 안전한 시작 위치에 두고 이동 경로를 다시 확인합니다.
6. 새 시험 작업물을 리밋스위치 통과 전 위치에 준비하고 프로그램 처음부터 재생합니다. 프로그램 내 초기화 이후에 실제 작업물이 진입해야 합니다.

## 최종 완료 체크

- 실제 입력으로 작업물 1개만 인식
- 지정 거리까지 대기하고 의도한 구간에서 동기를 수행
- 추종 방향과 상대 위치·자세가 기준 만족
- 동기 종료와 안전한 이탈 확인
- 중단 후 처음부터 재시험하는 절차 확인
- 검증한 프로그램·설정·시험 조건과 결과 저장
