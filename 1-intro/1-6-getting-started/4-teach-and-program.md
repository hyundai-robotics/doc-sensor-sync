# 1.6.4 튜토리얼 - 티칭과 단일 작업물 프로그램 구성

### 목표와 시작 조건

대기 위치, 동기 구간, 이탈 위치를 구분하여 티칭하고 작업물 1개에 대한 프로그램을 구성합니다. [각도 설정 및 엔코더 분해능 설정](3-calibration.md)을 완료하고, 사용할 툴/TCP와 시험 영역을 확인하십시오.

{% hint style="warning" %}
이 과정은 공정 출력 없이 추종과 이탈만 확인합니다. 도장·용접·그리퍼 출력이 포함된 생산 프로그램을 그대로 사용하지 마십시오.
{% endhint %}

### 1. 티칭할 위치 정하기

먼저 담당자와 다음 위치를 정하고 시험용 프로그램에 기록합니다.

| 스텝 | 역할 | 확인할 내용 |
| --- | --- | --- |
| S1 | 안전한 시작 위치 | 컨베이어·작업물과 간섭하지 않음 |
| S2 | 접근 위치 | 인터록 대기 위치까지 안전하게 이동 가능 |
| S3 | 인터록 대기 위치 | 동기 구간 진입 위치 근처이며 작업물 진입을 방해하지 않음 |
| S4 | 동기 구간 진입 위치 | 작업물에 접근하는 궤적과 추종 여유가 확보됨 |
| S5 | 짧은 동기 작업 위치 | 작업물과 툴의 상대 위치를 유지할 구간 |
| S6 | 동기 구간 마지막 위치 | 동기 종료 후에도 간섭 없이 이탈 가능 |
| S7 | 안전한 이탈 위치 | 동기 종료 후 이동 경로가 안전함 |

1. 컨베이어를 정지하고 시험 작업물을 티칭 기준 위치에 둡니다. 기준 위치와 리밋스위치로부터의 작업물 위치를 기록합니다.
2. 사용하는 센서가 컨베이어 동기로 설정되어 있는지 확인합니다. [3.5 스텝 데이터](../../3-user-interface/3-5-step-data.md)의 설명처럼, 센서 동기가 유효한 상태에서 위치를 기록하면 로봇 위치와 함께 작업물 위치가 기록됩니다. 실제 설정 화면에서는 동기 종류로 `컨베이어`를 선택합니다.
3. 같은 툴/TCP와 같은 작업물 기준을 유지하며 스텝을 기록합니다. 직선 컨베이어 동기 구간 `S4 ~ S6`은 단순한 짧은 직선 구간을 권하며, `L`보간을 사용합니다.
4. 각 동기 스텝의 위치 속성에서 `ss#` 항목에 사용하는 센서의 작업물 위치가 기록되어 있는지 확인합니다.
5. 시작·접근·이탈 구간도 포함하여 전체 경로의 간섭과 도달 범위를 확인합니다. 컨베이어 이동에 따른 시프트로 실제 재생 위치가 티칭 위치와 달라질 수 있습니다.

### 2. 대기 거리 지정

`cv.wait posi=...`의 대기 거리는 **리밋스위치에서 작업물이 이동한 거리**입니다. 직선 컨베이어에서는 mm 단위입니다.  
담당자와 실제 리밋스위치 위치, 티칭 기준 위치, 안전한 진입 가능 영역을 확인하여 값을 정하십시오. 대기거리 도달 후 로봇이 진입하는 동안에도 작업물은 계속 이동하므로, 진입 경로와 추종 여유를 함께 확인해야 합니다.

### 3. 프로그램 작성

```hrscript
    global cv
    cv=sync.Sensor(1)   # 사용할 센서 객체
    cv.sync reset   # 실제 작업물 진입 전 동기 종료 및 컨베이어 데이터 초기화
S1  move P,spd=100%,accu=1,tool=1 
S2  move P,spd=30%,accu=5,tool=1  # 동기 대기 위치로 이동
    delay 0.5
    cv.wait posi=200,sync=off   # 리밋스위치로 작업물 인식 및 지정 위치 이동까지 대기
    cv.sync on  # 동기 구간 시작
S3  move L,spd=30%,accu=1,tool=1  
    delay 1
S4  move L,spd=30%,accu=1,tool=1  
    delay 1
S5  move L,spd=30%,accu=1,tool=1  
    delay 1
S6  move L,spd=30%,accu=1,tool=1  
    delay 3
    cv.sync off # 동기 구간 종료
S7  move P,spd=100%,accu=1,tool=1  # 종료 위치로 이동
    end
```

### 완료 조건
- S1 ~ S7의 역할, 동기 구간 S4 ~ S6, 이탈 경로 구분
- 동기 스텝의 센서 위치 데이터, 보간 방식, 툴 데이터 확인
- 티칭 기준과 대기거리의 관계를 기록
- 초기화 이후에 실제 작업물 1개를 진입시키도록 준비
- 실제 프로그램의 구문·스텝·명령 배치를 담당자와 확인
