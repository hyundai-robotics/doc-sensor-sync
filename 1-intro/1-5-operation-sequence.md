# 1.5 조작 순서

처음 설정할 때는 아래 순서로 진행합니다. 각 단계에서 정상 결과를 확인한 뒤 다음 단계로 넘어가십시오. 직선 컨베이어와 작업물 1개를 사용하는 구체적인 절차는 [1.6 튜토리얼](1-6-getting-started/README.md)에 있습니다.

| 순서 | 작업 | 확인할 결과 |
| --- | --- | --- |
| 1 | 안전 절차·설비 구성·I/O 할당 확인, 기존 설정 백업 | 시험에 필요한 환경 구성 |
| 2 | 사용할 센서, 동기 종류·형태, 입력·출력 신호 설정 | 실제 설비와 설정 일치 |
| 3 | 리밋스위치와 엔코더 입력 확인 | 실제 리밋 입력의 변화와 raw 펄스 변화 |
| 4 | 컨베이어 각도·엔코더 분해능 설정 | 실제 이동 방향·거리와 설정의 대응 확인 |
| 5 | 동기 구간 티칭과 스텝 데이터 확인 | 로봇 위치와 사용할 센서의 위치 데이터 확인 |
| 6 | 대기·동기 시작·종료 명령 추가 | 단일 작업물 프로그램의 구문·명령 배치 확인 |
| 7 | 첫 시험 운전과 재시작 검증 | 추종·동기 종료·안전한 이탈 확인 |

아래는 기존 조작 순서도입니다. 실제 조작과 완료 조건은 위 표 및 튜토리얼 과정을 함께 참고하십시오.
