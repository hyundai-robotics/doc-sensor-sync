# 3.1.2 运行自动计算

在 [Settings > Application Parameters > Sensor Sync] 屏幕中，按 [Angle Setting] 显示角度屏幕。

{% hint style="info" %}  
如果传送带类型设置为圆形，则以下设置将被修改以定义圆形传送带的角度和中心。
{% endhint %}

![](../../_assets/image25.png)

1. 检查或手动设置当前配置的传送带角度。
2. 要进行自动计算，请按 [Auto Calculate]，输入教学程序号，计算结果将显示出来。

![](../../_assets/image26.png)

3. 按 [OK] 保存配置的值。
