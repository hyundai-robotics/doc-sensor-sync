# 3.1.1 程序教学

要执行输送带角度自动计算，首先按如下编写程序。

{% hint style="info" %}  
为了准确设置角度，请尽可能使每个记录位置相距较远（建议直线输送带至少1米）。
{% endhint %}


1. 选择一个新的程序进行输送带角度自动计算。
2. 将机器人工具尖端移动到输送带工件的特定位置并记录S1。

![](../../_assets/image22.png)

3. 移动输送带以移动工件，将机器人工具尖端移动到相同的特定位置并记录S2。

![](../../_assets/image23.png)

4. 将创建一个类似于以下的程序。

![](../../_assets/image24.png)


{% hint style="info" %}    
对于圆形输送带，需要三个位置来计算角度。再重复一次第3步。  
{% endhint %}
