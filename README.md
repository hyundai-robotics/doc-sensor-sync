# ${cont_model} 제어기 기능설명서 - 센서 동기(컨베이어, 프레스)

센서 동기는 엔코더 등의 외부 센서 신호를 받아 이동하는 컨베이어 작업물 또는 프레스에 로봇을 연동하는 기능입니다.

## 어디서 시작하면 되나요?

- **센서 동기를 처음 설정한다면:** [튜토리얼](1-intro/1-6-getting-started/README.md)에서 준비부터 입력 점검, 설정, 티칭, 첫 시험 운전까지 순서대로 진행하십시오. 로봇 기본 조작과 안전교육을 이수한 사용자를 위한 과정입니다.
- **원리와 구성이 궁금하다면:** [1. 개요](1-intro/README.md), [2. 시스템 구성 및 접속](2-system-config-access/README.md)을 참고하십시오.
- **화면·파라미터·명령을 찾는다면:** [3. 사용자 인터페이스](3-user-interface/README.md)를 참고하십시오.
- **프레스 동기를 사용한다면:** [프레스 동기 원리](1-intro/1-3-press-sync-principle.md)와 [프레스 동기의 티칭](4-teaching/4-2-press-sync-teaching.md)을 확인하십시오. 컨베이어 따라하기 과정을 그대로 적용하지 마십시오.
- **첫 설정이나 시험 중 문제가 생겼다면:** [증상별 점검표](1-intro/1-6-getting-started/6-troubleshooting.md)를 참고하십시오.

작업 전에 [사전 주의사항](0-about-this-manual/precautions.md)과 [안전 주의 사항](0-about-this-manual/safety-notice.md)을 읽으십시오. 화면과 예제의 수치는 설비별 권장 설정값이 아니며, 실제 제어기 버전과 설비 조건에 맞게 확인해야 합니다.
